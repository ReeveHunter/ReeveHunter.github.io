# CLAUDE.md — reevehunter.com

Reeve Hunter's site (GitHub Pages, custom domain in `CNAME`). Each top-level folder is its own small static project: plain HTML/CSS/JS, no build step, no shared framework. Reeve pushes to GitHub himself; commit locally and leave pushing to him. Before working on a project, read its folder's `CLAUDE.md` if it has one.

| Folder | What |
|---|---|
| `C64/` | **Cynthcart Controller** — Web MIDI editor for Cynthcart on Reeve's C64 (patches, setup, screen editing). Notes: `C64/CLAUDE.md`; the firmware is in Reeve's private local repo `cynthcart-kerberos`. |
| `flash/` | **Kerberos Flash** — flashes PRGs and EasyFlash CRTs to the Kerberos C64/C128 MIDI cartridge over Web MIDI (a port of Frank Buß's Kerberos App). Each slot stores a MIDI emulation; Cynthcart needs **DATEL / Siel / JMS** (with "None" the cartridge's MIDI is off). |
| `fatchip/` | **Fat Chip** tools. `fatchip/linktest/` = **Link Test**: one self-contained page that sends known MIDI bursts (notes, CCs/bends, clock, SysEx) to a Game Boy running Fat Chip GB (Setup > LINK TEST) and shows what its counters should read, to check what the MIDI adapter passes. Bursts must match `test/test_link.py` in the private local repo `~/Documents/GitHub/fat-chip-gb`. `fatchip/nes-lab/` = **NES Lab**: one self-contained page for testing MidiNES MIDI commands from the browser (voice tabs + on-screen keyboard, every CC as sliders snapped to real steps, Reeve's pitch-bend formula, a CC7 software envelope, numbered one-click experiments with a results sheet to paste back to Claude). `fatchip/keytar/` = **Keytar Monitor**: Web MIDI input logger for Reeve's Yamaha SHS-10 keytar, run as 14 guided steps (keys, bend, buttons, voices, channel, rhythm, tempo, styles, accompaniment, other buttons, idle); files each message under the running step, shows channels 1–16 (12–14 chords, 15 bass, 16 rhythm), drum notes with velocities, clock tempo and spread, and copies a report. `?sim` = a fake keytar. `fatchip/beatlab/` = **Beat Lab**: plays MidiNES drum kits in the browser from the decoded DMC data (read from the Sample Lab's IndexedDB, same origin, or a chosen `midines-dmc` folder; Reeve's categories / "has" embedded as a fallback). Each family (Reeve's categories) is measured (length; "pitch" = frequency below which half the energy lies) as 0–100 within the family and split into Ward-linkage groups Reeve can name. Kit slots for the SHS-10's drums (45 BD, 52 SD, 57 HH, 62 CY, 48 tom): samples (family, group, target length / pitch, spread, change = none / mostly / often / always, allowed DMC speeds, pitch drop at the end) or NES noise presets; one sample at a time with kick > snare > tom > cymbal (cymbal falls back to noise); kick + hat on one step can become one layered sample; accents / soft notes / beat 1 steer the target unless change is none; seeded shuffle bags. Test grooves (16-step, editable) or a live keytar over Web MIDI; NES-weighted mix with a noise volume and a backing chord on the pulses with a volume cap. Kit codes: `KIT-…` Crockford base 32 with a check character (version 2 layout in the page). `fatchip/samples/` = **Sample Lab**: plays the MidiNES's own DMC sample data in the browser (loaded by Reeve from his local `fat-chip/midines-dmc` folder into IndexedDB; never part of the site) at any of the 16 DMC pitches, each sample at its own pitch by default (bank A and B 0–21 at 15, the rest at 12); listen-and-tag library (category, "has" toggles for every sound a layered hit contains (kick, snare, hi-hat, open hat, cymbal, clap, tom, perc, vocal; pre-filled from the spreadsheet types and emoji), notes, keyboard driven; P plays on through the following notes for samples cut into parts) with a "sounds like" vote from the 5 nearest samples by sound (using Reeve's categories, else his by-ear guesses embedded from `midines-drums.md`). The original recording tools (Web MIDI trigger + AudioWorklet capture, slicing, play-through for levels) are folded away under "Recording tools". Zip export: WAVs + `analysis.csv` + `session.json`. `?sim` = fake MidiNES and audio. Device facts: `fat-chip/notes/midines.md`, `midines-plugins.md`, `midines-drums.md`. Plans: `~/Documents/GitHub/fat-chip/fat-chip-brief.md`. |

| `math/` | Math resources: Baylor page link (CheckItBU/ is no longer linked). |
| `platecutter/` | **Plate Cutter** — cuts sequential-photography plates (Muybridge) into transparent PNG sequences for a music video. Three steps: (1) drag a box on the first frame of each row, the tool guesses the row; (2) frame by frame, drag 4 corners (uncut view) → OK → see the cut, with an edge tolerance per row (override per frame) or "cut exactly on the corners"; (3) ping-pong preview at 6 fps, align on picture content (±px cap) or frame edges, join rows, arrow-key nudges, zip export with an After Effects scrub expression. Kept deliberately bare-bones (Reeve's call). Analysis in `core.js` (no DOM; `guessRow`, `cutQuad`), UI in `app.js`. `project.json` keeps each frame's first `guess` beside Reeve's `quad`, for tuning the guessing. |

Web MIDI pages (`C64/`, `flash/`, `CZ/`, `sightreading/`, `fatchip/linktest/`, `fatchip/nes-lab/`, `fatchip/samples/`, `fatchip/keytar/`, `fatchip/beatlab/`) need Chrome, Edge or Opera on a computer (or a Web MIDI browser app on iPad), and `https://` or `localhost`. To try a page locally: `python3 -m http.server` in the repo root, then open `http://localhost:8000/<folder>/`.
