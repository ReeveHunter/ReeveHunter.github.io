Game Boy Flash

ROM and bank manager for the EMS GB USB Smart Card 64M

This browser can't talk to USB devices. Open this page in Chrome or Edge on a Mac, Windows or Linux computer (Safari and Firefox don't support WebUSB).

Cartridge

Plug in the cart (with its USB cable) and click Connect. Close the EMS app or ems-flasher first if they're running.

No cart handy? — nothing is sent anywhere.

      Save RAM

      The cart has one 128 KB battery-backed save RAM shared by every game on both pages — playing a different game that saves can overwrite another game's save. Download it before switching games you care about.
