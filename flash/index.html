Kerberos Flash

PRG & EasyFlash CRT transfer for the Kerberos C64/C128 MIDI cartridge

This browser can't talk to MIDI devices. Open this page in Chrome, Edge or Opera (Safari doesn't support Web MIDI; Firefox needs a site-permission add-on).

MIDI connection

Start the C64 in the Kerberos menu before sending anything.

File

Loads into cartridge RAM and starts it. Nothing is flashed.
Pick the slot in the slot list.
Start settings
Reset mode

The CRT goes into the cartridge's upper 1 MB, which is the same flash as slots 10–25. Anything in those slots will be replaced.

Slots

    Names are read from the cartridge over MIDI in. Slots 10–25 share space with the EasyFlash image.
