Cynthcart Controller

Sound editing and patches for Cynthcart on the C64, over MIDI

This browser can't talk to MIDI devices. Use Chrome, Edge or Opera on a computer, or Chrome on Android. Safari (Mac, iPad, iPhone) has no Web MIDI; on an iPad, a browser app with Web MIDI support works.
MIDI access was granted without SysEx, so the Custom build + SysEx target can't send its messages. Allow SysEx for this site in the browser's settings and reconnect.

    How it works
    
      
      
    • Targets. Cynthcart 2.0 uses the original MIDI map. Custom build (CC only) is the Kerberos build before SysEx; Custom build + SysEx sets everything exactly, including octave, tuning, filter type and per-voice filter routing, and shows the patch name on the C64.
      • 
      
    • Greyed-out controls can't be reached on the chosen target; their value comes from the base preset.
      • 
      
    • Sending a patch loads the base preset first, then sets every value on top. On 2.0, only values that differ from the base preset are sent.
      • 
      
    • The page is the source of truth: Cynthcart can't send its state back, so changes made on the C64 keyboard aren't shown here.
      • 
      
    • Patches are kept in this browser. Export them to back them up or move them to another device.
