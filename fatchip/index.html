Fat Chip

The browser tools for Fat Chip, Reeve's C64 + Game Boy + NES instrument. They all need Chrome or Edge on a computer (Web MIDI).

Drums and samples

Sample Lab

Every MidiNES sample, played from its decoded data at any pitch.

Use it to listen, categorise and mark what each hit has (kick + hat…). The recording tools are folded away at the bottom.

start here · load the midines-dmc folder

Beat Lab

Build drum kits from the samples and hear them play.

Use it to set each drum's target, spread and change, tune the toms, try grooves (with humanize and Dilla time) or the live keytar, scrub the sweep, get a kit code.

uses the Sample Lab's data

Sound Sorter

Sort the drum samples into buckets of sounds that go together, and see the map it builds.

Use it to curate: sort rounds per family, name the percussion, match kits, then tag patches of the map (DnB, boombap, grimey…).

uses the Sample Lab's data

Testing the hardware

NES Lab

Try MidiNES commands: notes, every CC, pitch bends, envelopes, one-click experiments.

Use it to test something on the real MidiNES before Fat Chip uses it.

MIDI out to the MidiNES

Keytar Monitor

Everything the Yamaha SHS-10 sends, step by step, with a report to copy.

Use it to check keys, buttons, accompaniment, drum notes and clock.

MIDI in from the keytar

Link Test

Known MIDI bursts to a Game Boy running Fat Chip GB (Setup › Link Test).

Use it to see what the Teensyboy passes on: channels, CCs, bends, clock.

MIDI out to the Game Boy

The drum workflow: Sample Lab (load the data, tag the samples) → Sound Sorter (sort them into sounds that go together, tag styles) → Beat Lab (build and hear kits, copy the kit code) → Fat Chip 64's beat follow, with the keytar's rhythm playing the kit. The Keytar Monitor and NES Lab answer hardware questions along the way.
