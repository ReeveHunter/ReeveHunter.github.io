Beat Lab

Build MidiNES drum kits from the decoded samples and hear them play, before they go into Fat Chip.

No sample data in this browser yet. Load the midines-dmc folder in the Sample Lab first (it keeps it in this browser for this page too), or choose it here:

1Families and groups

Your categories, each split into groups of samples that sound alike (from the decoded data). Name the groups if you like; click a sample to hear it at its own pitch. Length and pitch are measured within each family: 0 = the shortest / lowest of that family, 100 = the longest / highest.

2Kit

Target: the length and pitch you want, within the family. Spread: how far from the target a substitute may be (0 = only the closest). Change: how often it substitutes. Speeds: which NES sample speeds it may use (faster = higher and shorter). With Change above “none”, accents push toward longer, fuller hits, soft notes toward shorter ones, and beat 1 a little longer. The sample channel plays one sound at a time: kick beats snare beats tom beats cymbal; a cymbal that loses moves to the noise channel.

3Play

Click the grid to change the groove (off → normal → accent → soft). The balance uses the NES's own channel weights, so the noise and pulse levels here are the ones Fat Chip would send (0–15). With a keytar connected, its rhythm plays the kit live (its Start / Stop and clock set the bar).

4Kit code

—

The whole kit and its seed in one short code with a check character, to write down, share, or (later) type into Fat Chip. Groups are numbered by family, so a code means the same kit as long as the categories stay the same.
