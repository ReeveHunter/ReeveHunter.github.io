Sound Sorter

Sort the MidiNES drum samples into buckets of sounds that go together. Every round adds to a map of how the sounds relate, and patches of the map can be tagged by style and character.

No sample data in this browser yet. Load the midines-dmc folder in the Sample Lab first (it keeps it in this browser for this page too), or choose it here:

2Map

Sounds you put in the same bucket pull together; ones you keep apart push away. Lines show what you've sorted (green together, red apart). Click a dot to hear it and select it; Shift-click to add; drag on empty space to select a patch; drag a dot to move it.

Suggested groups

Sounds that keep landing in the same bucket. Select a group to hear it or tag it.

3Save and share

Everything stays in this browser. Export to back it up or to hand to someone; importing a file merges their rounds, percussion names, types and tags with yours (rounds are never counted twice). No sample data goes in the file.
